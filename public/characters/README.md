Each one gets sliced into a grid of jigsaw pieces automatically by the game code, nothing needs to be cut up by hand. To add another character, drop a square-ish image in this folder and add one entry to src/data/levels.js with its file name, a title, and how many rows/cols to cut it into. Everything else (level select tile, piece scatter, saving) works on its own.
